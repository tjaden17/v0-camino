# Camino - Claude Code Configuration

## Project Overview
Camino is a Next.js application. See `README.md` for full project details.

## Active Development Branch
Development work happens on feature branches, not `main`. When working on this
repository, check `git branch` to confirm you are on the correct branch.

The `main` branch only contains the initial scaffold. All meaningful code and
documentation lives on the active feature branch.

## Common Commands
```bash
# Install dependencies
pnpm install

# Run dev server
pnpm dev

# Build
pnpm build

# Type check
pnpm tsc --noEmit
```

## Key Directories
- `app/` — Next.js app router pages and API routes
- `components/` — Shared UI components
- `lib/` — Utilities and shared logic
- `docs/` — Project documentation and sprint notes
- `scripts/` — Utility scripts
